## TODO — Migration Gap Tracking

### 🔴 Gap 6 — Audit Trail Completeness (CRITICAL)

**Status:** ☐ Not Verified

**Objective:**
Ensure every data mutation is recorded in the audit trail with full traceability.

---

**Required Rule:**

```id="g6a"
EVERY write → audit log entry → SAME transaction
```

---

**Disallowed:**

```id="g6b"
Data mutation without audit entry
Audit written outside transaction
Partial audit for multi-step operations
```

---

**Verification Steps:**

Search for audit usage:

```id="g6c"
grep -r "audit" backend/
grep -r "log" backend/
```

Check critical flows:

* ☐ certificate create/update/finalize
* ☐ test completeTest
* ☐ saveResults
* ☐ item add/update/remove
* ☐ payment updates
* ☐ status transitions

For each:

* ☐ Is there an audit entry for every mutation?
* ☐ Is audit written inside the SAME transaction?
* ☐ Are multi-step operations fully audited (not partially)?

---

**Pass Condition:**
All data changes are fully traceable via audit logs.

---

**Fail Condition:**
Any mutation occurs without corresponding audit entry.

---

**Risk if not fixed:**

* No traceability
* Impossible debugging
* Compliance failure
* Loss of system trust
