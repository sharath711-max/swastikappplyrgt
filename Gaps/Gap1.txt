## TODO — Migration Gap Tracking

### 🔴 Gap 1 — Write Path Inconsistency (CRITICAL)

**Status:** ☐ Not Verified

**Objective:**
Ensure all data mutations follow a single controlled service layer, matching Python production behavior.

**Required Rule:**

```
ALL writes → service layer ONLY → repository/DB
```

**Disallowed:**

```
Route → repo/DB (direct)
Multiple services writing independently
```

**Verification Steps:**

* Search for direct DB access:

  ```
  grep -r "db.run" backend/
  grep -r "update(" backend/
  grep -r "insert(" backend/
  ```
* Check each occurrence:

  * ☐ Is it inside a service layer?
  * ☐ Is it bypassing business logic?

**Pass Condition:**
All writes go through a single service layer (e.g., `workflowService` / domain service)

**Fail Condition:**
Any route or controller directly writes to DB/repository

**Risk if not fixed:**

* Business rules bypassed
* Audit skipped
* Transaction inconsistency
* Silent data corruption
